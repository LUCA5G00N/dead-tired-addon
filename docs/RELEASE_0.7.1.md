# Dead Tired 0.7.1: for whom the bell tolls

Zip: `dist/DeadTired-0.7.1.zip`.

A small one. The your-turn sound was a drum roll pretending to be a bell. Now it's a real bell: the Undercity toll.

## Changed
- **The your-turn bell** is the Undercity bell toll (`/dt gamble sound on`; still off unless you switch it on). If your turn comes round again while it's still tolling, it doesn't start a second one. If your client can't play it, you get the old chime.

## Install
1. Quit WoW. Back up `WTF\Account\<you>\SavedVariables\DeadTired.lua`.
2. Delete the old `Interface\AddOns\DeadTired` folder.
3. Unzip `DeadTired-0.7.1.zip` into `Interface\AddOns\`.
4. Log in. Everything comes with you.
