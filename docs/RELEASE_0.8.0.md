# Dead Tired 0.8.0: the Restless Dead Pilgrimage begins

Zip: `dist/DeadTired-0.8.0.zip`.

The guild addon for <DEAD TIRED>. Still optional, still quiet, and now it wants you to go for a walk.

## New: guild quests (`/dt quests`)
- **The Sleeping Bag.** The seven steps to the Cozy Sleeping Bag, from the burned tower in the Barrens to Thoradin's Wall. Each step ticks itself off when you've done it. **Next step** points the Waypointer at the next one. Rekindle is optional; nobody's judging your campfire.
- **The Library.** All 39 of the library books, book by book: which you've handed in, how many more to the next reward from Owen Thadd, and **Nearest book** to point you at the closest unread one on your continent. Click any book for a waypoint.
- **The guild board.** Who's done how much of each, and who got to the bag first. Hover over a book to see which guildies have already handed it in.

Progress comes straight from your quest log, so nobody can fake it. It's shared with guildies running the addon so the board works; `/dt quests share off` takes you off every board. Only these quests are shared, nothing else from your log.

## Install
1. Quit WoW. Back up `WTF\Account\<you>\SavedVariables\DeadTired.lua`.
2. Delete the old `Interface\AddOns\DeadTired` folder.
3. Unzip `DeadTired-0.8.0.zip` into `Interface\AddOns\`.
4. Log in. Everything comes with you.
