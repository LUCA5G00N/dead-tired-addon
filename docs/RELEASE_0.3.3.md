# Dead Tired 0.3.3: the dead, in colour

Zip: `dist/DeadTired-0.3.3.zip`.

The guild addon for <DEAD TIRED>. Still optional, still quiet, still useless outside the guild.

## New
- **Death notices name the fallen in their class colour**, in chat and in the graveyard
  (`/dt graveyard`). Thank EchoOfMany. Anyone the guild roster can't place stays plain.
- The colours are the game's own, so **shamans are blue**. Paladins keep the pink.
- `/dt debug rip <name>` shows how a guildie's notice would look, without anyone having to die.

A small feature in a patch number. The dead were never good at counting.

## Known scruffiness
- **Switching skin** still doesn't repaint a window that's already open. Close it and open it
  again. It's on the list.

## Install
1. Quit WoW. Back up `WTF\Account\<you>\SavedVariables\DeadTired.lua`.
2. Delete the old `Interface\AddOns\DeadTired` folder.
3. Unzip `DeadTired-0.3.3.zip` into `Interface\AddOns\` (you get `Interface\AddOns\DeadTired\DeadTired.toc`).
4. Log in. Everything from 0.3.2 comes with you.
