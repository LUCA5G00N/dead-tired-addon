# dead-tired-addon

The **<DEAD TIRED>** guild addon for WoW Forever. Optional for members: it adds guild features
that work between everyone who runs it, and stays quiet for everyone else.

- **`DeadTired/`**: the addon (copy this folder into `Interface\AddOns`).
- **`docs/`**: the roadmap, and one brief plus walk-sheet per build round.
- **`reference/`**: read-only material the build sessions copy patterns from (Tim's Wizardry
  addon and the Forever API reference). Not part of the addon.

Build sessions: read `CLAUDE.md` first.
